# Verkaufsvideo — Drehbuch (max. 4:00 Min)

Sprechtext ≈ 330 Wörter → ca. 2:45 reine Sprechzeit. Der Rest ist Luft für
Screen-Momente. Lieber ruhig sprechen als hetzen.

---

## Vorbereitung

**Einen Tag vor der Aufnahme (wichtig für den Follow-up-Radar!):**

1. `python -m job_agent.main web` starten, einloggen.
2. Pipeline im Demo-Modus laufen lassen (Suche → „Jobs finden").
3. Zwei Bewerbungen auf **„Eingereicht"** setzen.
   → Am Aufnahmetag „Fällig nach (Tagen)" auf **1** stellen: der Radar ist gefüllt.
4. In der URL-Inbox 1–2 Links ablegen (wirkt echter als eine leere Liste).

**Kurz vor der Aufnahme:**

- [ ] Browser: 100 % Zoom, **F11-Vollbild**, helles Theme, keine Lesezeichenleiste
- [ ] Windows: Benachrichtigungen aus (Focus Assist / Bitte-nicht-stören)
- [ ] Auflösung 1920×1080, Mauszeiger ruhig führen, nicht kreisen
- [ ] Demo-CV bereitlegen: `data/profile/sample_cv.pdf`
- [ ] Server läuft, einmal Probeklick durch den ganzen Pfad (unten)
- [ ] Mikrofon testen (10-Sekunden-Probe aufnehmen und anhören)

**Aufnahme-Tools (Windows, kostenlos):**

- **OBS Studio** (empfohlen): Szene „Bildschirmaufnahme", 1080p/30fps, Mikro als zweite Spur
- Schnell-Variante: **Win+G** (Xbox Game Bar) → Aufnahme
- Schnitt: **Clipchamp** (in Windows enthalten) — Versprecher rausschneiden, fertig
- Profi-Tipp: Erst Bildschirm in Ruhe aufnehmen, **Voiceover danach** einsprechen — 
  deutlich entspannter als gleichzeitig klicken und reden

## Klickpfad-Spickzettel (neben den zweiten Monitor legen)

1. Login → 2. Profil: CV-Drop → Profil erstellen → 3. „Lebenslauf bewerten" →
4. Suche: „Jobs finden" (Animation stehen lassen!) → 5. Top-Job → Score scrollen →
Verfügbarkeit → 6. Anschreiben → Export (PDF) → E-Mail senden (Dry-Run) →
7. Bewerbungen (Statistik) → 8. Follow-ups (Entwurf aufklappen) →
9. Inbox (JD einfügen → Bewerten) → 10. Interview-Vorbereitung → Schluss.

## Profi-Tipps

- **Pro Szene ein Take** aufnehmen und in Clipchamp aneinanderhängen — nicht
  alles in einem Rutsch versuchen.
- Nach jedem Klick **1 Sekunde stillhalten**, damit der Schnitt sauber wird.
- Zahlen verkaufen: „92 Prozent", „vier Agenten", „sechs Kriterien" ruhig betonen.
- Falls Zeit knapp wird: Szene 0:10 (Problem) kürzen — nie die Feature-Szenen.
- Erste und letzte 5 Sekunden entscheiden: Hook laut und klar, Schlusssatz mit Pause.
